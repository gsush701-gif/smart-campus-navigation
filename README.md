# Smart Campus Navigation and Facility Analytics System

C++ campus navigation and facility analytics system using a custom hash table,
BFS on an undirected graph, and a general department tree.

## Build and run

```bash
g++ -std=c++11 -Wall -Wextra -pedantic -Iinclude src/*.cpp -o campus
./campus                  # loads data/
./campus testdata/ties    # loads another data directory
```

See README.txt for the full documentation.
